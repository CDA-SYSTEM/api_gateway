# Política de Seguridad / Security Policy

## Español

### Versiones Soportadas

| Versión | Soportada |
|---------|-----------|
| 1.0.x   | ✅ Sí     |

### Reportar una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en el **CDA System —
API Gateway**, por favor repórtala de inmediato a los titulares del
proyecto. **No abras un issue público.**

Pasos para reportar:
1. Envía un mensaje a través del repositorio oficial de GitHub
2. Incluye una descripción detallada de la vulnerabilidad
3. Proporciona pasos para reproducir el problema
4. Espera la confirmación de recepción antes de compartir detalles

### Compromiso

- Recibirás una respuesta en un plazo máximo de 48 horas
- Trabajaremos para resolver la vulnerabilidad lo antes posible
- Te mantendremos informado del progreso

### Buenas Prácticas

- No compartas credenciales, API keys o tokens en el código
- Usa variables de entorno para configuración sensible
- Mantén las dependencias actualizadas
- Ejecuta `npm audit` regularmente

## English

### Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |

### Reporting a Vulnerability

If you discover a security vulnerability in **CDA System —
API Gateway**, please report it immediately to the project holders.
**Do not open a public issue.**

Steps to report:
1. Send a message via the official GitHub repository
2. Include a detailed description of the vulnerability
3. Provide steps to reproduce the issue
4. Wait for acknowledgment before sharing details

### Commitment

- You will receive a response within 48 hours
- We will work to resolve the vulnerability as soon as possible
- We will keep you informed of progress

### Best Practices

- Do not share credentials, API keys, or tokens in code
- Use environment variables for sensitive configuration
- Keep dependencies updated
- Run `npm audit` regularly
