size BIGINT,    data BLOB,    created_at TIMESTAMP,    deleted_at TIMESTAMP);CREATE INDEX idx_files_deleted_at ON storage_system.files (deleted_at);```The `data` column stores the actual file binary as a BLOB. `deleted_at` enables soft-delete: files with a non-null `deleted_at` are considered deleted.## Entity Relationships (Cross-Service)```mermaiderDiagram    AuthService_User ||--o{
