# Backend API OverviewThe **API Gateway** is a [NestJS](https://nestjs.com/) application written in TypeScript. It serves as the single entry point for all client-facing HTTP requests, providing:- **Routing & Proxying** ÔÇö Forwarding requests to the appropriate microservice- **Authentication** ÔÇö JWT token validation and role-based access control- **File Handling** ÔÇö Multi-part file upload proxied to the storage service- **Response Enrichment** ÔÇö Joining data from multiple services into unified responses- **API Key Security** ÔÇö Internal service-to-service authentication## Request Flow```mermaidsequenceDiagram    participant Client    participant Gateway as API Gateway    participant CombinedGuard    participant Service as Target Microservice    Client->>Gateway: HTTP Request + Bearer Token    Gateway->>CombinedGuard: Validate Token + Roles    alt Public Route (@Public)        CombinedGuard-->>Gateway: Skip auth    else Authenticated        CombinedGuard-->>Gateway: Token OK + User Attached    end    Gateway->>Service: Proxy Request + API Key Header    Service-->>Gateway: Response    Gateway-->>Client: Standardized JSON Response```## Key Design Decisions- **Global ValidationPipe** ÔÇö All incoming requests are validated with `whitelist: true` and `forbidNonWhitelisted: true`- **Global ResponseInterceptor** ÔÇö All responses are wrapped in a standard `{ statusCode, message, data, timestamp, path }` envelope- **Global CombinedGuard** ÔÇö Every route is protected unless explicitly marked with `@Public()`- **File uploads before form submission** ÔÇö Files are uploaded to the storage service first, then the resulting URLs are included in the form payload
