# Código de Conducta / Code of Conduct

## Español

### Nuestro compromiso

Como miembros del equipo de desarrollo del **CDA System — API Gateway**,
nos comprometemos a mantener un entorno inclusivo, respetuoso y libre
de acoso para todos los participantes del proyecto.

### Estándares

Comportamiento positivo incluye:
- Usar lenguaje respetuoso e inclusivo
- Aceptar críticas constructivas con apertura
- Enfocarse en lo que es mejor para el proyecto
- Mostrar empatía hacia los demás miembros del equipo

Comportamiento inaceptable:
- Comentarios sexualizados o avances no deseados
- Trolling, insultos o comentarios despectivos
- Acoso público o privado
- Publicar información privada de otros sin permiso

### Aplicación

Las infracciones pueden ser reportadas a cualquier titular del
proyecto. Todas las quejas serán revisadas e investigadas de
manera justa y confidencial.

### Atribución

Este Código de Conducta está adaptado del *Contributor Covenant*,
versión 2.0, disponible en https://www.contributor-covenant.org

## English

### Our Pledge

As members of the **CDA System — API Gateway** development team,
we pledge to maintain an inclusive, respectful, and harassment-free
environment for all project participants.

### Standards

Positive behavior includes:
- Using respectful and inclusive language
- Accepting constructive criticism openly
- Focusing on what is best for the project
- Showing empathy towards other team members

Unacceptable behavior:
- Sexualized comments or unwelcome advances
- Trolling, insults, or derogatory comments
- Public or private harassment
- Publishing others' private information without permission

### Enforcement

Violations can be reported to any project holder. All complaints
will be reviewed and investigated fairly and confidentially.

### Attribution

This Code of Conduct is adapted from the *Contributor Covenant*,
version 2.0, available at https://www.contributor-covenant.org
